# Slides

Presentation decks on the project's results, for partners and collaborators. Each opens full screen in the browser; use
the arrow keys or swipe to move between slides, and hover a chart for its values.

- **[Phase 0 findings](https://aidotse.github.io/cafl4ds/slides/p0-findings/)** — *calibrating label-free health readers
    on toy data.* Which signals catch collapse, forgetting, instability and quality loss in a self-supervised model, and
    which readers Phase 1 carries.
- **[Phase 1 findings](https://aidotse.github.io/cafl4ds/slides/p1-findings/)** — *does a backbone that keeps learning
    on a real stream gain, and can we see it degrade?* The open loop on BDD100K, reading degradation, and adapting
    versus freezing. It grows with Phase 1, and shows each study's audit state.

The decks are built from the same artifacts as these docs, and go live with each release. Their sources are in
[`slides/`](https://github.com/aidotse/cafl4ds/tree/main/slides).
