# Positive control — data-driven surprise / shock, the deployment-relevant instability (P0.4.1)

**What this substudy is.** The *data-driven* companion to [P0.4.0](P0.4.0.md). Where P0.4.0 forces divergence with a
pathological learning rate (the clean, controllable lever), P0.4.1 asks the deployment-relevant question: does the
gradient-norm instrument fire on data surprise — an out-of-distribution burst arriving mid-stream — and can it tell a
*transient, recoverable* shock from a *runaway* one? Same instrumented streaming loop and same grad-norm instrument as
P0.4.0; the forcing lever is now the data, not the learning rate.

The headline result is a sharpening of what the instrument actually reads: the grad norm reads reconstruction-error
*magnitude* (a *content* shock), not distributional novelty. A saturating (out-of-range) shock fires cleanly; an
in-range distribution shift — even one that destroys image structure — does not.

## Why toy scale is valid (with a caveat P0.4.0 did not have)

Like divergence, a surprise *spike* is a fast, local response (a large loss on a hard batch → a large gradient), so the
*mechanism* reproduces at toy scale. The caveat, flagged in the original design and borne out here, is that surprise
magnitude depends on how well the base distribution is modelled: an under-trained MAE finds everything surprising,
voiding the contrast. So the base is genuinely warmed to competence first (raw reconstruction MSE `0.215 → 0.058` over
~4 epochs) and the run is gated on confirming that descent before any burst is injected. What does *not* transfer from
toy scale is the *genuine deployment surprise pole* (a correlated distribution drift over an unending horizon,
interacting with the closed active-selection loop) — that is Phase-1, the same hand-off made for the forgetting
correlation question (P0.3.8).

## Why MAE — and why **raw MSE, not `norm_pix`** — is the vehicle

MAE + SGD is carried from P0.4.0 (unbounded loss, undamped optimizer). The new choice is turning `norm_pix_loss` off.
The default MAE (P0.1/P0.4.0) normalizes each target patch to unit variance before the MSE, which caps the per-patch
loss near 1.0 for *any* unpredictable content — a competent MAE already sits at ~0.97, so surprise has no headroom to
register in the loss *magnitude*, and the grad norm cannot read it (empirically, even a saturating noise shock under
`norm_pix` gives only a ~1.5× grad blip). Surprise detection needs the loss magnitude to track reconstruction error, so
the vehicle uses raw reconstruction MSE. This is the direct analogue of P0.4.0's "the loss must be unbounded" finding —
one level deeper, *inside* MAE.

## Design — a burst spliced into a warmed base stream

A hand-built stream over the same tiny MAE (img 32): `warm_steps=300` of a base distribution (STL-10) to reach
competence, `burst_steps=8` of a shock, then `tail_steps=100` of the base again so a transient spike's *recovery* is
observable. Two arms from a seed-reset, bit-identical start, the base steps indexed identically across arms so only the
burst-window content differs:

| arm | burst window | prediction |
| -- | -- | -- |
| **shock** | the injected burst | grad norm spikes (change point); then recovers *or* runs away |
| **control** | the base (no injection) | grad norm stays in the base band (quiet reference) |

The gate reads the two-sided contrast at the same steps (shock burst vs. the control's *same* steps — not the shock's
own pre-burst band, since the base loss is still descending across the burst, so the counterfactual "no shock" reading
is the control at those exact steps). Flat LR (no scheduler) and grad-clip off, so the burst is the sole perturbation
and a blow-up is not masked.

**The burst content is the experiment.** `burst_kind=noise` injects uniform-random images scaled by `burst_scale`: at
amplitude 1 they are in the trained `[0, 1]` range; above 1 they **saturate out of range** (a sensor-corruption-style
content shock). `burst_kind=dataset` injects an in-range distributional OOD (CIFAR-100, optionally grayscale or
phase-scrambled) — the *naive* surprise vehicle.

### Reads

- **The gate (two-sided change point).** The shock's burst-window peak grad norm ≥ `change_ratio` × the control's
    same-step peak (fires), the base is competent (warm loss descended), the burst is genuinely surprising (shock burst
    loss ≥ `surprise_ratio` × the control's same-step loss), and the control is flat (its own within-arm burst/base band
    < `control_quiet_ratio`).
- **Transient vs. runaway (severity ≠ permanence).** Reported: does the spike recover to the base band in the tail
    (transient) or run away (divergence)? The `burst_scale` **amplitude** is a data-shock severity dose-response at
    fixed `lr_op`.
- **Lead time on a runaway.** Where the shock triggers a divergence, the grad-norm blow-up vs. the loss NaN — the P0.4.0
    leading-indicator read, data-triggered.
- **The `lr_sweep` negative control.** LR-driven divergence at `lr > threshold` is shock-independent.

## Findings

Base: STL-10, tiny MAE img 32, SGD momentum 0.9, raw MSE, warmup & clip off; seed 0, reproduced seed 1.

- **Two-sided gate: PASS** (both seeds). The base is competent (loss `0.215 → 0.058`). The saturating noise shock
    (`burst_scale=4`) fires: burst loss **≈30× the control's same steps**, and a grad-norm change point of **78× (seed
    0\) / 74× (seed 1)** the control's same-step peak, while the control's own within-arm burst/base band stays flat
    (`0.06×`). The spike then **recovers** to the base band in the tail — a large severity with **zero permanence** (the
    P0.3 severity ≠ permanence analogue).
- **The refutation — distributional OOD does not fire.** An in-range distributional burst produces reconstruction error
    *comparable to the base* and no separable grad-norm change point (shock/control same-step contrast, seed 0): color
    CIFAR `surprise 1.18× / fire 1.97×`, grayscale CIFAR `1.04× / 2.27×`, **phase-scrambled CIFAR `0.54× / 1.16×`**
    (structure destroyed, yet the loss *drops* — smooth texture is *easier* to inpaint than natural images), and even
    in-range noise `0.80× / 1.51×`. All sit at or below the natural grad-norm variance floor (a healthy grad norm
    fluctuates ~2–4× on batch noise). MAE reconstruction difficulty tracks local inpaintability, not distributional
    novelty, so the grad norm is *not* a distribution-shift detector for this vehicle — it reads a *content* shock
    (error magnitude), which an in-range shift does not produce.
- **Severity dose-response on the shock amplitude (fixed `lr_op=1`).** `scale 1` no fire (`1.5×`) → `scale 2` fire `18×`
    (transient) → `scale 4` fire `78×` (transient) → `scale 8` fire `484×` → runaway (NaN@step 314) → `scale 16` fire
    `5×10⁹` → runaway (NaN@305). The transient→runaway threshold on the *data* axis is between scale 4 and 8, and the
    **lead time shrinks with severity** (`scale 8` → 14 steps, `scale 16` → 5 steps) — the same inverse
    lead-time/severity coupling P0.4.0's operating-envelope note predicts, now data-triggered. NaN at step 314 (the
    burst window is `[300, 308)`) shows the shock **triggered** the runaway: it completes in the *base tail*, not during
    the burst.
- **The `lr_sweep` negative control.** At `lr = 3, 10` both the shock *and* the control go non-finite at the
    **identical** step (8, then 5) — this is warm-phase, LR-driven divergence (P0.4.0), which fires long before the
    step-300 burst, so it is **shock-independent**. An in-range shock doesnt necessarily lower the divergence threshold;
    only a large out-of-range *content* shock (the amplitude ladder) triggers divergence at a base-stable LR.

## Insights

- **The instrument reads a content shock (error magnitude), not distribution shift.** The clean positive control is a
    saturating out-of-range corruption; an in-range distribution shift — even structure-destroying phase-scramble — is
    invisible to the grad norm because it does not raise the reconstruction error above the base. A live grad-norm
    monitor would catch sensor corruption / saturation / gross artifacts, **not** a subtle covariate drift. That bound
    is the substudy's point.
- **Two nested vehicle findings on the loss.** P0.4.0: the loss must be *unbounded* (MAE MSE, not SimSiam cosine) to
    diverge. P0.4.1: *within* MAE, the loss must be *raw* (not `norm_pix`) for its magnitude to track surprise. Both are
    "the vehicle changes what the instrument can see."
- **Severity ≠ permanence, and lead time ∝ 1/severity — on the data axis.** A severe-but-recoverable shock (large spike,
    full recovery) and a runaway differ by *amplitude* at a fixed LR, with a real threshold between them; past it, the
    warning the grad norm gives shrinks as the shock worsens — the data-driven face of P0.4.0's operating envelope.

## Build

No new library code — P0.4.1 reuses the P0.4.0 grad-norm-instrumented `StreamingLoop` unchanged. The substudy is a new
harness + config:

1. **Harness** — `scripts/positive_control_data_surprise.py`: builds the base batches and the burst (uniform noise ×
    `burst_scale`, or the `data_b` distributional OOD), splices the `warm → burst → tail` stream, runs the shock +
    control arms across the `lr_sweep`, and evaluates the two-sided change-point gate + the recovery / lead-time reads.
1. **Config** — `configs/positive_control_data_surprise.yaml`: the vehicle (`ssl.norm_pix_loss=false`, `optim=sgd`, clip
    off), the stream shape (`warm/burst/tail_steps`), the burst knobs (`burst_kind`, `burst_scale`), `lr_op` /
    `lr_sweep`, and the gate thresholds.

## How to run

The whole read (gate + LR ladder) runs in one session (seconds–minutes on CPU):

```bash
uv run python scripts/positive_control_data_surprise.py            # the two-sided gate (noise shock, scale 4)
```

The data-shock **severity dose-response** (no-fire → transient → runaway), and the refuted distributional-OOD ladder:

```bash
uv run python scripts/positive_control_data_surprise.py 'burst_scale=1'   # in-range: no fire
uv run python scripts/positive_control_data_surprise.py 'burst_scale=8'   # over threshold: runaway (lead time)
uv run python scripts/positive_control_data_surprise.py burst_kind=dataset data_b=cifar100_scrambled  # non-fire
```

Read: the shock's burst-window grad-norm spike vs. the control's same steps (fire), whether it recovers in the tail
(transient) or runs away (the amplitude threshold + lead time), and — on the `dataset` bursts — that an in-range
distribution shift does *not* separate from the base.
