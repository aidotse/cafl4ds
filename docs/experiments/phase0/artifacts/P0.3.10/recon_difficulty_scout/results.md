# Recon-difficulty scout (P0.3.10/Q2)

Inpainting difficulty of each candidate phase-B domain, measured at the **phase-B-start condition** — a decoder warmed
on task A (12 decoder-only epochs, encoder frozen), then norm-pix reconstruction loss read on each domain at that fixed
decoder state (8 mask draws averaged). In MAE the reconstruction-loss magnitude sets the gradient magnitude, hence the
encoder-update pressure a phase-B domain applies, so a fair far-shift test wants a domain whose difficulty is at least
as high as task A's (the P0.4.1 finding: recon loss reads inpaintability, not novelty).

| domain | norm-pix recon loss | ratio to task A |
| -- | -- | -- |
| task-A Imagenette (held-out) | 0.578 | 1.00× (match target) |
| EuroSAT (satellite, 64px → 224) | 0.496 | **0.86×** (slightly easier) |
| DTD (texture, native high-res) | 0.729 | **1.26×** (harder) |

Read: the two far domains **bracket** task-A difficulty. DTD is the harder (more update pressure) → the conservative
primary vehicle; EuroSAT the easier bracket. Generated by `scripts/scout_recon_difficulty.py` (one Gaudi card).
