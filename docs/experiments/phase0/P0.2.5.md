# Positive control 6 — partial-collapse dose-response (P0.2.5)

Every earlier collapse sub-study ([P0.2.0](P0.2.0.md) → [P0.2.4](P0.2.4.md)) drives SimSiam (or Barlow) to a
*mathematically-forced* trivial optimum — the fully-collapsed extreme. The thermometer has been dipped in ice (a genuine
healthy baseline) and in boiling water (forced collapse), and reads the two ends apart. It has never been checked for a
**scale in between**. P0.2.5 builds a controlled *partial*-collapse continuum and asks whether the projector detectors
read intermediate severity — the incipient, gradual degradation that Phase-1 early-warning monitoring actually needs.

This is a **falsification / go-no-go probe**, not a ✅-gate: it can only *retroactively invalidate* the "read at the
projector" instrument choice (if the detectors are blind to the middle), not *complete* the calibration. Its value is
cheap insurance on the joint-embedding leg of the Phase-0 portfolio, and it closes three audit gaps off one experiment —
C1 (incipient-severity monotonicity), C2 (does the projector surface track the backbone we actually care about), and C4
(an independent downstream anchor for "healthy").

## Why this exists (what the forced-collapse calibration left open)

The collapse ✅ was earned against *maximally-forced* collapse. But a deployment monitor's whole job is to fire **early**
— while degradation is mild and still fixable — and nothing in P0.2.0–P0.2.4 shows the instruments respond to anything
short of the global trivial optimum. Three specific gaps follow, and all three live on the same missing object, a
partial-collapse continuum:

- **C1 — incipient-severity monotonicity.** Do the projector detectors read a *graded* scale, or only trip once collapse
    is already total? This is the one property early warning depends on, and the only failure mode without a severity
    dose-response (contrast P0.4's dose-response + lead-time and P0.3's erosion-depth map). Partially pre-answered by
    P0.2.2's D3 (RankMe is monotone in collapse *depth* on the deep-forcing side) — but that never populates the
    *healthy-to-mild* range this probe targets.
- **C2 — surface coupling.** The project cares about **backbone** health, yet the calibration concluded we should read
    the **projector** and distrust the backbone. Under *forced* collapse the two surfaces are coupled (the ablation
    collapses everything), so whether projector geometry faithfully tracks backbone health under *gradual* degradation
    is untested.
- **C4 — an independent anchor for "healthy."** The healthy baseline is currently certified by RankMe re-expanding — the
    instrument vouching for itself. The monitor already computes kNN/linear probes, but the probe-accuracy contrast
    (healthy vs. collapsed) is never surfaced as independent evidence that "healthy" is *actually useful* downstream.

## Methodology — two mechanistically distinct knobs, one ladder

Vehicle and regime are fixed to the point-collapse core: intact SimSiam (the widened-predictor P0.2.1 healthy corner) on
**IID × 40 epochs** — the regime where RankMe@proj is *known* to separate, so "cannot read the middle" is never
confounded with "cannot read at all". Probes are **on** (C2 and C4 both need downstream accuracy). The redundancy
vehicle (Barlow) is deliberately out of scope — a natural sibling follow-up if the point-collapse result is clean.

A single `severity` `s ∈ [0, 1]` slides from the healthy pole to the collapsed pole. Rather than trust one construction
of the continuum, P0.2.5 runs **two knobs that reach collapse by different mechanistic paths**, so agreement between
them is a genuine robustness test rather than redundancy:

- **`blend` (loss blend `collapse_alpha = s`).** The training loss is `(1 − s)·L_healthy + s·L_collapse`, interpolating
    the *whole objective* between the two calibrated poles. `s = 0` is byte-identical to the certified healthy arm;
    `s =   1` reproduces the *exact* forced-collapse positive control (predictor bypassed, stop-gradient off).
- **`softsg` (soft stop-gradient `stopgrad_beta = 1 − s`).** Only the single *essential* anti-collapse mechanism is
    weakened — a controlled fraction of the gradient flows through the target branch (`β·z.detach() + (1−β)·z`), with
    the predictor kept **on** throughout. Its collapsed pole is a genuinely *different* collapsed state
    (collapse-via-no-stop- gradient), reached along a different path.

Both ladders start at the *identical* healthy pole; their collapsed ends differ by design. Each `(knob, seed)` runs the
full ladder from one bit-identical initialization (the seed is reset per rung, so the ladder is a clean within-seed
trajectory), across **seeds 0–3** — the min/mean-across-seed robustness the rest of P0.2 uses.

## The three reads (all off the one ladder)

- **C1 (monotonicity)** — for each projector instrument, the Spearman rank correlation of `severity` vs. the reading
    along the ladder. A detector reads the middle iff that correlation has the collapse-consistent sign and is large
    (|ρ| ≥ 0.9) across seeds, and the reading spans a meaningful range between the poles.
- **C2 (surface coupling)** — the Spearman correlation of RankMe@proj vs. the *backbone* probe accuracy across rungs:
    does the surface we read predict the utility of the surface we care about as degradation grows gradually?
- **C4 (independent anchor)** — the backbone probe-accuracy contrast (healthy → collapsed), grounding "healthy" in real
    downstream usefulness rather than in the geometry instruments agreeing with themselves.

## Pre-registered reading (fixed before the runs)

The two knobs are read together as exactly three outcomes, committed to in advance so the result is a finding rather
than a post-hoc story:

- **Both monotone** → C1 passes robustly; the instruments read incipient severity, and the monotonicity is *knob-
    invariant* (a property of the thermometer, not of one contrived continuum). The strongest positive outcome.
- **Both a sharp step** (flat, then an abrupt jump at a critical severity) → collapse is a phase transition however it
    is approached, so the detectors genuinely cannot read the *incipient* range at toy scale. A clean negative — flagged
    as the mode's defining open risk, never folded into the ✅.
- **They disagree** (one ramps, one steps) → the monotonicity is *knob-dependent* — an artifact of how the continuum is
    built, not a stable property. The subtlest outcome, and exactly the kind of thing worth catching cheaply now rather
    than in Phase 1.

Toy-scale caveat throughout: the thresholds do not transfer (every P0 number is tuned at tiny ViT / 32px / small
`proj_dim`); what P0.2.5 tests is the *shape* of the response — monotone vs. step, coupled vs. decoupled surfaces —
which is the part that can legitimately inform Phase 1.

## Implementation additions (code)

1. **Two SimSiam knobs** — `collapse_alpha` (loss blend) and `stopgrad_beta` (soft stop-gradient) on
    `cafl4ds/ssl/simsiam.py` (threaded through `build_simsiam`), both no-ops at their defaults so every pre-P0.2.5 run
    stays byte-identical. The soft stop-gradient lives in `training_step` (a pre-detach blend of the target), leaving
    the `_neg_cosine` boolean untouched.
1. **Partial-collapse harness** — `scripts/partial_collapse.py` (+ `configs/partial_collapse.yaml`) runs one severity
    ladder per `(knob, seed)` in a session and emits `comparison.json = {sweep, ladder, monotonicity}`: the per-rung
    final geometry (both surfaces) + probe accuracy, and the C1/C2/C4 correlations.
1. **Unit tests** — endpoint equivalences (`collapse_alpha = 1` ≡ forced collapse; the blend is the exact convex mix;
    `stopgrad_beta` is wired into the target-branch gradient; both knobs validated to `[0, 1]`).

## Findings

Two grids, read together. First a **coarse** ladder (2 knobs × 4 seeds × `s ∈ {0, 0.25, 0.5, 0.75, 1.0}`); then —
because the coarse ladder put the *entire* healthy→collapsed drop inside its first, unsampled interval — a **refined**
low-severity ladder (2 knobs × 2 seeds × `s ∈ {0, 0.02, 0.05, 0.10, 0.15, 0.25}`) that resolves the transition. Both on
the Gaudi HPUs (STL-10, IID × 40ep, probes on). The resolved outcome is the pre-registered **both monotone**: once the
severity axis is sampled finely enough, the two mechanistically distinct knobs *agree* on a smooth, monotone ramp, and
the projector detectors read the incipient band.

**1. The coarse ladder shows an *apparent* cliff — but leaves the transition unresolved.** RankMe@proj (mean across 4
seeds):

| severity `s` | 0.0 (healthy) | 0.25 | 0.5 | 0.75 | 1.0 (collapsed) |
| -- | -- | -- | -- | -- | -- |
| **blend** RankMe@proj | 29.33 | 3.75 | 1.85 | 1.62 | 1.42 |
| **softsg** RankMe@proj | 29.90 | 3.37 | 1.80 | 1.57 | 1.36 |

By `s = 0.25` the reading has already fallen from ~29 to ~4 — ~92 % of the healthy→floor range — on every seed and both
knobs. Read alone this looks like a phase transition at the first nonzero severity. But note *where* the drop lives:
entirely inside the **first interval** `(0, 0.25]`, which the coarse grid never samples. Whether that is a true
discontinuity or a steep-but-smooth ramp compressed into low severities is simply unresolved at this spacing — the
coarse grid's very first rung already sits near the collapsed floor.

**2. Refining the low-severity region resolves the cliff into a smooth, monotone ramp (both knobs, both seeds).**
Sampling five points inside `(0, 0.25]`, RankMe@proj descends *gradually*, not in a step — mean across 2 seeds:

| severity `s` | 0.0 | 0.02 | 0.05 | 0.10 | 0.15 | 0.25 |
| -- | -- | -- | -- | -- | -- | -- |
| **blend** RankMe@proj | 27.24 | 27.73 | 21.56 | 14.21 | 7.74 | 3.88 |
| **softsg** RankMe@proj | 29.16 | 27.17 | 20.76 | 9.74 | 5.35 | 3.22 |

The mild band `s ∈ [0.05, 0.15]` is now clearly **populated** — RankMe@proj takes intermediate values ~21 → ~6, neither
healthy (~28) nor collapsed (~4). The apparent cliff was an artifact of **too-coarse severity spacing**; at adequate
resolution the response is a continuous descent. The fine grid's endpoints reproduce the coarse ladder (`s=0.25` ≈
3.2–3.9 vs. the coarse 3.4–3.8), so the two grids are consistent — the fine grid just fills in the middle the coarse one
jumped over.

**3. C1 verdict — the projector detectors read the incipient band monotonically (early warning is demonstrable at toy
scale).** On the refined ladder RankMe@proj is monotone in severity in **all four runs** (Spearman ρ = −1.0 in 3/4,
−0.943 in the 4th; collapse-consistent sign, |ρ| ≥ 0.9), and the two other projector geometry instruments agree —
variance@proj and uniformity@proj are monotone in every run. So the gap the audit's C1 named **is closed** for the
calibrated projector surface: the detectors do not merely trip at total collapse, they track a graded
healthy→mild→collapsed scale. This **strengthens** rather than invalidates the "read at the projector" choice, and
corrects the coarse-grid impression that toy-scale collapse is a bifurcation with no readable middle. (The earlier
per-trajectory "attractor depth" reading was the same under-resolution artifact: what looked like a basin-boundary jump
in the *settled* reading is a smooth function of severity once the axis is resolved.)

**4. C2 — the projector surface tracks the backbone; the backbone's own geometry is noise-limited over the mild range.**
RankMe@proj vs. backbone RankMe stays strongly positive along the refined ladder (ρ = +0.94 / +0.94 / +1.0 / +0.83), and
vs. backbone linear-probe accuracy moderately positive (ρ ≈ +0.83 / +0.84 / +0.83 / +0.67). So "read at the projector"
does **not** betray the backbone — where degradation exists the two surfaces move together, now confirmed over a
*smooth* ramp rather than a step. The backbone's *own* geometry and probe readings, by contrast, wobble
non-monotonically rung-to-rung across this mild range: the backbone is **less** collapsed than the projector (the
surface story), so its small true signal sits under per-rung noise. That is a signal-to-noise limit on the backbone as a
*readout* — precisely why the calibration reads the projector — not a coupling failure.

**5. C4 — downstream accuracy falls healthy → collapsed, an independent anchor that "healthy" is genuinely useful.**
Backbone probe accuracy drops from the healthy to the collapsed pole — kNN ≈ 0.29 → 0.21, linear ≈ 0.30 → 0.24 (STL-10
chance = 0.10) — so "healthy" is grounded in real downstream utility, not just in RankMe vouching for itself. Over the
*mild* interior the per-rung probe values are noisy (±~0.02 swamps a small monotone trend at this resolution), so C4 is
read as the endpoint contrast, not a fine ramp; the drop is modest and the backbone stays clearly above chance even at
full projector collapse (less collapsed than the projector, consistent with the surface story).

**Aside — `offdiag_cov`@proj is a correct null here.** Its values stay negligible (~5×10⁻⁴–1×10⁻³) across both ladders;
the redundancy detector does not track *point* collapse, exactly as [P0.2.2](P0.2.2.md) calibrated. Its apparent
Spearman is noise on a null instrument, not a signal.

**Bottom line.** The refinement **resolves** P0.2.5 in favour of the strongest pre-registered outcome. The apparent
cliff in the coarse sweep was under-resolution — the whole drop sat inside a single unsampled interval; a finer
low-severity ladder recovers a smooth, monotone, knob- and seed-invariant ramp, and the projector detectors read the
incipient (healthy-adjacent) band that early warning depends on. C1 **passes**; C2 (projector tracks backbone) and C4
(utility confirms the axis) hold. The collapse ✅ is **strengthened** — the joint-embedding detectors read graded
severity, not just the forced extreme. The remaining Phase-1 question is narrower than "can they read a middle at all":
it is whether *real-scale* collapse presents as gradual a ramp as this toy vehicle does (thresholds never transfer; only
the response *shape* does).

## How to run

Each `(knob, seed)` runs the full severity ladder in one session (probes on — C2/C4 need them). On the Gaudi HPUs the
grid splits across the two cards (see [`../../developing.md`](../../developing.md)):

```bash
# card 0 — the loss-blend knob, seeds 0–3
for s in 0 1 2 3; do
  ./scripts/run_gaudi_dev.sh -m /mnt/stl10 gaudi-env-cafl4ds:latest 0 \
    python scripts/partial_collapse.py sweep.knob=blend seed=$s device=hpu \
    data_root=/mnt/stl10 hydra.run.dir=outputs/P0.2.5/blend_seed$s
done
# card 1 — the soft-stop-gradient knob, seeds 0–3
for s in 0 1 2 3; do
  ./scripts/run_gaudi_dev.sh -m /mnt/stl10 gaudi-env-cafl4ds:latest 1 \
    python scripts/partial_collapse.py sweep.knob=softsg seed=$s device=hpu \
    data_root=/mnt/stl10 hydra.run.dir=outputs/P0.2.5/softsg_seed$s
done
```

The **low-severity refinement** (finding 2) just overrides the ladder onto the unresolved first interval — same harness,
finer `severities` (2 seeds suffice to distinguish a ramp from a step):

```bash
./scripts/run_gaudi_dev.sh -m /mnt/stl10 gaudi-env-cafl4ds:latest 0 \
  python scripts/partial_collapse.py sweep.knob=blend seed=0 device=hpu \
  'sweep.severities=[0.0,0.02,0.05,0.1,0.15,0.25]' hydra.run.dir=outputs/P0.2.5_lowres/blend_seed0
```

Fast network-free smoke (CPU, synthetic — wiring only):

```bash
uv run python scripts/partial_collapse.py sweep.knob=blend data=synthetic img_size=16 epochs=6 \
  batch_size=32 stream.support_per_class=8 stream.query_per_class=8 stream.era_eval_per_class=5
```
