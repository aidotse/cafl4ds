## The value proposition

Phase 0's job is to build thermometers for a self-supervised model's health that work without labels — because in
deployment (Phase 1+) there's no answer key to check the model against. Different failure modes need different
thermometers: collapse (P0.2), divergence (P0.4), forgetting (P0.3), quiet degradation (P0.5).

Forgetting — the model quietly losing an old skill as it learns a new one — is the project's core continual-learning
worry, but P0.3 kept hitting a wall: the model P0.3 used (MAE, which learns by filling in masked-out pixels) barely
forgets at all, and its one label-free thermometer (the reconstruction-error gap) was weak and, worse, needed a saved
batch of the old data to read — which a "data flows past once and is gone" stream can't provide.

So P0.6 asks a clean, two-part question by switching the model to a joint-embedding type (SimSiam — it learns by pulling
two views of the same image together, and has an extra internal "projector" surface MAE lacks):

- **A1**: Can we get a trustworthy label-free forgetting thermometer at all? (Even if it needs a saved batch.)
- **C3**: Can we get one that needs no old data whatsoever — a true rolling monitor for a transient stream?

The test rig is always the same two-arm setup: one arm is made to forget (a "positive control"), a twin arm is protected
so it doesn't. A good thermometer must light up on the first and stay quiet on the second.

## Results

Setup that actually induces forgetting. Only a far-away new task triggers it — teaching the model satellite imagery
(EuroSAT) after everyday photos (Imagenette) craters the old skill; a near task (CIFAR) doesn't budge it. Even then the
damage is shallow and seed-fragile (fires on ~4–5 of 5 random seeds, never a landslide).

**P0.6.0 (A1)** — success, but not the reader we expected. We thought the projector's collapse-detectors (the P0.2
geometry suite) would double as forgetting-detectors. Mostly they don't — they're tuned for a different failure, and one
of the pair actively mis-signals (it even points the wrong way). The other half of the pair does light up reliably, but
it only tells you the model is in a far-shift regime, not how *much* it forgot — so it rides along as a bonus second
reader, not the main one. What actually works is representation drift — measuring how far the model's internal picture
of the old data has moved. Read against a saved batch of old data, drift tracks the forgetting cleanly on every seed and
even scales with how deep the crater is. So: a trustworthy label-free reader exists — it's drift, not geometry — but it
still leans on that saved batch.

**P0.6.1 (C3)** — success, through a narrower keyhole. We cut the crutch: instead of saved old data, pin the drift
reference to a batch of the current stream (no memory of the past needed). It still works — but only a specific flavor:
the coordinate-frame churn at the projector fires on all 5 seeds, while the plain backbone drift that won A1 fails and
even inverts. The reason is intuitive: once you reference the far-away new data, the healthy twin's backbone gets shaken
up by that unfamiliar input too, so the two arms look alike there — only the projector (the most plastic surface) still
cleanly reflects the forgetting arm respecializing. So a no-old-data-needed reader exists — but you have to look at
exactly the right surface.

One honest caveat on both. Drift measures change, and some of that change is benign "just learning the new thing." What
separates harmful forgetting from healthy learning is the protected twin — which we have in the lab but won't have in
deployment. So P0.6 delivers calibrated instruments, not a finished deployment monitor; making drift self-interpreting
without the twin is a Phase-1 problem.

## The one-line takeaway

Switching from MAE to a joint-embedding model turned the forgetting thermometer on — and the working reader is
representation drift (not the collapse-geometry we assumed): trustworthy with a saved batch (A1 ✅*), and even
past-data-free if you read the projector's frame-churn specifically (C3 ✅*). Both are real but shallow, and both still
need the lab's protected-twin control to be trusted — which is the bridge into Phase 1.
