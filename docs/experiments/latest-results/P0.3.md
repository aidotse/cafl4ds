## The value proposition

Phase 0's job is to build thermometers for a self-supervised model's health that work without labels — because in
deployment (Phase 1+) there's no answer key to check the model against. This study tackles **forgetting**: the model
quietly losing an old skill as it learns a new one. That is the project's core continual-learning worry — a model that
trains forever on a passing stream must not silently overwrite what it already knew.

The model here is **MAE**, which learns by blanking out patches of an image and trying to fill them back in. The
question: can we build a positive control that makes an MAE genuinely forget, and then find a thermometer — ideally a
label-free one — that catches it?

The test rig is two arms. One trains hard on task A, then only on task B (the forgetting arm). A twin gets a **replay**
protection — task B interleaved with revisits of A — so it should *not* forget. A per-task probe (a small labelled
readout, used only to *measure*, never in deployment) is the ground truth; the real goal is a label-free signal that
tracks it.

## Results

**The headline is a non-result: MAE barely forgets.** Across a long hunt — every knob on toy STL-10 (P0.3.0–P0.3.3),
then the canonical CIFAR-100 forgetting benchmark (P0.3.4) — a from-scratch MAE simply refused to forget. Task B never
overwrites task A hard enough. A fire came *only* from a contrived setup: a big pretrained ImageNet-MAE (a deep,
hard-won skill worth losing), a far-apart task split (Imagenette → CIFAR), and replay matched to that skill for the
healthy twin. Even then the damage was shallow.

**The two-sided instruments are calibrated — after a scare (P0.3.6 → P0.3.9).** A single-seed fire (P0.3.6) looked like
success but *did not replicate*: only 1 of 5 random seeds fired (a lucky draw). A lever hunt (P0.3.9) recovered a
genuinely seed-stable 5/5 fire by settling a deep, consolidated skill and dwelling longer on task B. So the ground-truth
readers — Backward Transfer and Forgetting Measure — now have a trustworthy positive control. The catch: they need the
labelled per-task probes the deployment stream does not have.

**The label-free reader is weak and confounded.** Representation drift (how far the model's internal picture of the old
data has moved) worked on a *supervised* fire but did not transfer to the MAE fire. That leaves only the
reconstruction-error gap — which turns out to be mostly a side-effect of the replay arm, not real forgetting, and which
*false-fires ~10× on a purely cosmetic shift*: recolour the images grayscale and it screams even though the
representation is intact (P0.3.8). It is readable only with the two-arm control sitting beside it.

The honest caveat — the star on the ✅. Every MAE crater we induced is ~fully recoverable: relearn task A and it snaps
back, about as fast as if it had never been lost. That is *severity, not permanence*. The genuinely dangerous case —
deep, *permanent* forgetting — never appeared at toy scale, even at a doubled horizon. Whether a long, correlated
real-scale stream finally breaks MAE's resistance is the defining Phase-1 question.

## The one-line takeaway

MAE largely **resists** catastrophic forgetting — the two-sided BWT/FM instruments are now seed-stable-calibrated
(recommend 🟡 → ✅ for the instruments), but they need labels, the one label-free reader is weak and confounded, and every
crater is recoverable — so the genuine, *permanent* MAE forgetting pole stays an open Phase-1 risk (P0.3 ✅\*).
