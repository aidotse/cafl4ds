## The value proposition

Phase 0's job is to build thermometers for a self-supervised model's health that work without labels — because in
deployment (Phase 1+) there's no answer key to check the model against. This study calibrates the thermometer for
**instability**: training going off the rails, either because the loss blows up to infinity (divergence) or because a
jarring chunk of data knocks the model sideways (a shock).

The thermometer on trial is the **gradient norm** — the size of the update the model tries to make on each step. The
intuition: a healthy run takes steady, modest steps, while a run about to explode takes wildly growing ones. The real
prize is **lead time** — catching the runaway a few steps *before* the loss actually goes non-finite, while there is
still time to react.

The test rig is two arms measured at the same steps. One is driven unstable (a pathological learning rate in P0.4.0, or
an out-of-distribution data burst spliced into a warmed-up stream in P0.4.1); the healthy twin trains normally. The
gradient norm must blow up on the first and stay bounded on the second.

## Results

**This is the cleanest mode in Phase 0 — because its mechanism actually reproduces at toy scale.** Collapse and
forgetting are hard to induce on a tiny model; an optimization runaway is not. The grad-norm gate fires two-sided (the
healthy arm stays finite and learning, the control goes non-finite by ≥100×), *leads* the loss NaN by ~5 steps (the
payoff), and is *specific* — it stays bounded on the collapse control, so it is not just a generic "something's wrong"
alarm.

**P0.4.1 sharpens what the shock reader actually reads:** reconstruction-error *magnitude* — a *content* shock — not
distribution shift. A saturating out-of-range noise burst fires it, but genuinely out-of-distribution-yet-plausible data
(CIFAR, grayscale, scrambled) does not move it at all. It reads "how hard is this to reconstruct", not "how novel is
this".

**The load-bearing lesson is a vehicle finding.** The early-warning signal exists *only* under two conditions together:
an **unbounded** loss (MAE's raw pixel error — a bounded loss like SimSiam's just collapses instead of diverging)
**and** an **undamped** optimizer (plain SGD, where the step size grows with the gradient and feeds the runaway). Under
the *standard* modern setup (AdamW + a normalized loss), both valuable reads vanish: AdamW absorbs the blowup (NaN with
zero warning), and the normalized loss shrinks the shock to a bare 1.47× blip. Both counterfactuals are preserved as
artifacts.

The caveat, now a recommendation. Because the signal is vehicle-contingent, P0.4 hands Phase-1 a concrete design choice
rather than an open gap: to *keep* the grad-norm early warning, favour an undamped optimizer + raw loss; if Phase-1
adopts AdamW + a normalized loss, early-warning instability is an unsolved problem — no instrument here provides it.

## The one-line takeaway

Instability is the cleanest-calibrated mode — the **gradient norm** fires two-sided, specifically, and ~5 steps *ahead*
of the loss NaN — but only under an unbounded loss + undamped optimizer; under a standard AdamW + normalized-loss setup
the early warning disappears, so the ✅ ships with a concrete design recommendation to Phase-1 (P0.4 ✅).
