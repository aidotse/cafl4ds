## P0.3.7

From the [savings-audit substudy](phase0/P0.3.7.md). The plan was to audit the label-free MAE fire
([P0.3.6](phase0/P0.3.6.md)) with the **savings paradigm** — truly forgotten ⇒ relearning task A is as slow as from
scratch; retained ⇒ relearning is fast. This is the P0.3.5 analogue, but a genuinely different experiment: in MAE the
objective is decoupled from the probe readout, so a probe crater could be a mere representation *rotation* with task A
intact.

**Result: the savings test could not be run meaningfully on this fire.** The P0.3.6 crater is too shallow — its bottom
sits far above the from-scratch floor — so there is no relearning-speed gap to score. The from-scratch pole is also the
wrong control: it lost *everything*, not task A specifically.

- **What we can still say (weakly):** the forgotten encoder retains task-A structure — after a matched relearn budget it
    behaves like the held encoder and far above a random-init ViT-B, consistent with "MAE resists catastrophic
    forgetting." But that is close to what a shallow crater already means, so it is a consistency check, not an
    independent verdict.
- **What stays open:** whether a genuinely *deep* MAE crater would be permanent (savings≈0) or recoverable. The savings
    paradigm needs a deeper fire *and* a valid competent-but-task-A-destroyed reference to discriminate — and that
    reference is unconstructible here (from-scratch too weak, pretrained too strong since task A ⊂ ImageNet). →
    [P0.3.8](phase0/P0.3.8.md) / Phase-1.
- **Recon is the cleaner readout, again:** probe curves are muddied by a shared fresh-decoder warming dip, but the
    MAE-native recon loss is monotone and decisive — reinforcing P0.3.6 that the trustworthy label-free reader is the
    reconstruction loss.

This does not change the mode verdict (✅ rests on the two-sided gate P0.3.6). It was meant to *characterize* the fire
and instead found that the characterization instrument is uncalibrated on a fire this shallow. New harness:
`savings_steps`/`savings_lr` + `_savings_probe` (label-free 3-init relearn) +
`TinyViTEncoder.reset_parameters_from_scratch` (a genuine naive baseline). Next: **P0.3.8** (hard-disjoint vehicle
toward the genuine pole + a recon-instrument FP check), then **P0.4** (instability / grad-norm).

Promoted the savings `comparison.json` to [`artifacts/P0.3.7/`](phase0/artifacts/P0.3.7/).
