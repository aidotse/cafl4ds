## P0.3.0

From the [forgetting-gate substudy](phase0/P0.3.0.md) — the first calibration of the **forgetting** failure mode. Goal:
first approach at showing a passing two-sided gate (instruments fire on induced failure mode, and stay quiet otherwise)
for catastrophic forgetting, focusing on a single distinct-class corner. Vehicle: a **split-task** MAE with a single
**replay** toggle — both arms train phase A identically, then the PC trains task B only (respecializes, forgets) while
the healthy arm replays A (holds). Read as the two-phase accuracy matrix → Backward Transfer / Forgetting Measure, plus
backbone drift and a reconstruction readout.

**Result: forgetting made real, gate PASSES — but only on a *distinct-task* split, and only through the transfer
probe.**

> **⚠ Revised by [P0.3.2](P0.3.2.md):** this single-seed "pass" did not survive multi-seed / precise-probe
> replication.Calibration escalates to CIFAR-100 ([P0.3.4](P0.3.4.md)).

- **The task split is the lever.** An arbitrary class split (`{0–4}` vs `{5–9}`) shows no forgetting even with an
    escalated MAE (task-A *rises* during B-only training): a random-init ViT already probes highly on the 5-way task (no
    headroom), and MAE learns transferable structure, so training on B helps A too. A distinct split (task A = vehicles,
    task B = animals) craters task A: delta between PC and healthy vehicles at 3.4× contrast.
- **BWT/FM are the reliable forgetting signal; drift is not.** `cka_drift` separates only weakly and near-threshold (a
    coin-flip: 0.047 → fail, 0.051 → pass across identical-regime runs) and `cosine_drift` **inverts** (larger in the
    healthy arm), so drift is **demoted to a reported observation**, not gated. The MAE-native recon signal corroborates
    via *relative retention* (PC held task-A reconstruction worse than replay) but is reported, not gated.
- At this toy-scle, the crater is genuine but **modest and near the toy-scale noise floor** (−0.05 to −0.07 across
    runs), so the gate rests on the robust BWT/FM contrast. Synthetic data cannot host this mode at all.

analogue of the collapse PC).
