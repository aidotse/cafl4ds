# P0.4.1 — data-driven surprise / shock, the grad-norm change point ✅ DONE

**Status: DONE (2026-08-06).** The data-driven companion to P0.4.0 and the **last Phase-0 substudy** — the
instability/divergence mode (and Phase 0's instrument calibration) is now fully calibrated.

**Headline.** The gradient norm reads reconstruction-error **magnitude** (a **content** shock) — **not distributional
novelty.** A saturating out-of-range shock fires cleanly; an in-range distribution shift does not.

**Result (seed 0, reproduced seed 1; STL-10 base, tiny MAE img32, SGD momentum 0.9, raw MSE, warmup & clip off).**
Two-sided change-point gate **PASS**. After warming the MAE to competence (raw recon loss `0.215 → 0.058`), a
saturating-noise burst (`burst_scale=4`) fires: burst loss **≈30×** and a grad-norm change point **78× (seed 0) / 74×
(seed 1)** the control's *same steps*, while the base-only control stays flat (`0.06×` within-arm). The spike then
**recovers** to the base band in the tail — a large severity with **zero permanence** (the P0.3 *severity ≠ permanence*
analogue).

**The refutation — distributional OOD does not fire.** An in-range distributional burst gives reconstruction error
comparable to the base and no separable grad-norm change point (shock/control same-step, seed 0): color CIFAR
`surprise 1.18× / fire 1.97×`, grayscale `1.04× / 2.27×`, phase-scrambled `0.54× / 1.16×` (structure destroyed, yet loss
*drops* — smooth texture is easier to inpaint), in-range noise `0.80× / 1.51×` — all at/below the natural grad-norm
variance floor (~2–4×). MAE recon difficulty tracks local **inpaintability**, not novelty.

**Severity dose-response (fixed `lr_op=1`, on the shock amplitude).** `scale 1` no fire → `2/4` fire `18×/78×` and
**recover** (transient) → **`8` fire `484×` → runaway** (NaN@314, **lead 14**) → `16` runaway (NaN@305, **lead 5**).
Threshold on the *data* axis between scale 4 and 8; lead time **shrinks with severity** — the data-driven face of
P0.4.0's operating envelope. NaN@314 (burst = `[300, 308)`) shows the shock *triggered* the runaway (it completes in the
base tail).

**Negative control — LR-divergence is shock-independent.** In the `lr_sweep` ladder, shock and control go non-finite at
the identical step (8 at `lr=3`, 5 at `lr=10`) — warm-phase LR divergence (P0.4.0), long before the step-300 burst. Only
a large out-of-range *content* shock triggers divergence at a base-stable LR.

**Two nested vehicle findings.** P0.4.0: the loss must be **unbounded** (MAE MSE, not SimSiam cosine). P0.4.1: *within*
MAE it must be **raw** (`norm_pix_loss=false`) — per-patch normalization caps the loss near 1.0, erasing the magnitude
surprise needs.

**Build.** No new library code — reuses P0.4.0's grad-norm-instrumented `StreamingLoop`. New harness
`scripts/positive_control_data_surprise.py` + `configs/positive_control_data_surprise.yaml`: warms a base MAE, splices a
`noise`/`dataset` burst, runs shock + control across an LR ladder, evaluates the two-sided change-point gate + recovery
/ lead-time reads.
