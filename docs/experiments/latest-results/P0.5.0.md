## P0.5.0

From the [MAE shortcut degradation & the P0.2 suite on trial — the mask-ratio vehicle](phase0/P0.5.0.md), the anchor of
the P0.5 mode (its companion [P0.5.1](phase0/P0.5.1.md) drives the same mode with an over-powered decoder). Motivated by
the forgetting arc's conclusion ([P0.3.9](phase0/P0.3.9.md)) that catastrophic forgetting is a borrowed frame MAE
resists — so this is the first control aimed at how MAE *actually* breaks.

**Status: runs complete (from-scratch MAE, Imagenette, 5 seeds) — the mask lever does not induce the mode; the P0.2
suite's quality blind spot on MAE stands. (Mode-status label is the user's call — see index.md.)**

The mask-0.1 shortcut fails to crater the frozen probe on every seed: a strong from-scratch MAE resists this shortcut,
keeping a useful representation while the reconstruction loss looks healthy — the "loss lies" footgun, read *within* the
shortcut arm (the mask ratio changes the task, so cross-arm loss is not apples-to-apples — that cleaner demonstration is
[P0.5.1](phase0/P0.5.1.md)'s). No label-free reader tracks the (small) crater: `uniformity` is *noise* (it fires only on
the smallest-crater seed, direction flipping seed to seed), `alignment` is quiet, and RankMe stays high (the
precondition). A nuance that sends the crux to P0.5.1: the mask lever partially *erodes* rank on some seeds, so it is
not a clean full-rank vehicle. **Limiting caveat carried to the P0.5 audit:** the healthy baseline shows real but
*modest* learning — far from a competitive representation — which bounds how hard any shortcut can crater. The negative
is on-theme (MAE resists, echoing the forgetting arc); a genuine crater likely needs the degrade-from-competent path,
now pursued in [P0.5.2](phase0/P0.5.2.md) (a pretrained, capacity-gated MAE against which the candidate MAE-native
readers are put on trial).
