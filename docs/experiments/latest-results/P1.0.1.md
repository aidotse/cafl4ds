## P1.0.1

From the [arm-alignment divergence sub-study](phase1/P1.0.1.md) — the retroactive certificate for Phase-0's comparison
method. Every Phase-0 positive control aligns its arms by re-seeding each so it rebuilds "the same" stream, then
`zip`-ing their step-indexed series (`positive_control.py`). P1.0.1 tests that assumption against the **shared-iterator
oracle** (`scripts/measure_divergence.py` + `cafl4ds/harness.py`): materialize the stream once and have every arm draw
from that one buffer, so the data is *provably* identical by construction. It measures per-step **data identity** and
**health-trajectory divergence**, and splits any drift into a **stream-construction** contributor (does a same-seed
rebuild match the oracle's data?) and an **in-arm-RNG** contributor (the residual on identical data — augmentation, MAE
masking, dropout, BatchNorm), the latter isolated by a deliberate desync control.

**The verdict: the same-seed `zip` is certified, exactly.** Across the 2×2 C×I STL-10 matrix a same-seed rebuild is
bit-identical to the oracle and the health trajectory does not diverge — because `EraStream`'s RNG is isolated from the
global RNG (so re-seeding reconstructs the data and leaves the training RNG untouched) and Phase-0 re-seeds *per arm*
(so the in-arm draws re-lock too). The in-arm desync control moves every cell — proving the zeros are earned, not a
blind spot — with the largest sensitivity on from-scratch SimSiam's projector; that lever is exactly what the per-arm
re-seed neutralizes.

**The disposition: sequential same-seed stays the default runner.** It is certified equivalent to the oracle and it
composes — the arms are independent, so N of them can be added, farmed out, or run one-at-a-time with a single backbone
in memory and heterogeneous horizons. The co-stepped oracle is retained not as a runner but as the standing
**re-certification check**, to re-run if the data/RNG path changes (per-sample augmentation, a source touching the
global RNG, GPU nondeterminism) or if disk-bound streams at BDD scale make its single shared pass worth the compute.

**Status: ✅ complete; 2×2 C×I STL-10 certification green** (data bit-identical, matched trajectory zero, in-arm control
sensitive; also runs network-free on `data=synthetic`). Backing runs in
[`phase1/artifacts/P1.0.1/`](phase1/artifacts/P1.0.1/); measurement logic guarded by `tests/unit/test_harness.py`.
