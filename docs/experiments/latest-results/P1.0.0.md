## P1.0.0

From the [loop-integration sub-study](phase1/P1.0.0.md) — the engineering foundation for Phase 1. Consolidates the
scattered Phase-0 pieces (the frozen floor B5 measured only at run-end, a separate positive-control script per failure
mode) into **one multi-arm harness** (`cafl4ds/harness.py` + `scripts/run_harness.py`) that runs the **live / PC / B5**
arms and co-logs them into a single **canonical `comparison.json`** (the base schema Phase 1 owns here; later studies
extend it but can fall back). Default alignment is Phase-0's proven **sequential same-seed arms** (live and B5 share the
step grid exactly); the shipped smoke PC is the cheapest calibrated fire — SimSiam with anti-collapse off — with the
per-mode PC scripts pluggable into the same slot. The shared-iterator oracle (Option A) is deferred to
[P1.0.1](P1.0.1.md).

Deliberately **number-free**: the deliverable is that the rig *runs*. The full 2×2 C×I STL-10 smoke passes in every
corner — the rig runs, the live instruments move in the right direction (the live arm reproduces P0.1.0 cell-for-cell),
the collapse PC fires identically as a fixed control, the frozen B5 floor holds constant, and every value stays finite —
plus a long-horizon resampled-image run that stays finite with flat (plateauing) memory. Reading movement *as
degradation* is the mode studies' job (P1.3 / P1.4), not this one's.

**Status: ✅ built; C×I STL-10 smoke + long-horizon leak check green** (`I=pretrained` warm-started by an IID pre-pass,
`scripts/pretrain.py`; also runs network-free on `data=synthetic`). Backing runs in
[`phase1/artifacts/P1.0.0/`](phase1/artifacts/P1.0.0/); wiring guarded by `tests/unit/test_harness.py`.
