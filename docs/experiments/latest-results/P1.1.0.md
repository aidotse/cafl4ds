## P1.1.0

From the [healthy-movement null sub-study](phase1/P1.1.0.md) — the first P1.1 piece. Phase 0 warned that a healthy
backbone *also* moves its health instruments, so a reading off the correlated BDD drive means nothing until we know how
much a healthy drive moves. P1.1.0 measures that null with a **matched IID control** — the walk's exact images, steps
and batch sizes, only shuffled — so any walk-vs-IID gap comes from the correlation alone. It also sizes the labelled
canary's statistical power (the P1.0 audit's C2), and sweeps how **familiar** the drive's frames are to the warm-start
well, because P1.3 will drive on new frames and needs to know whether familiarity narrows the null.

**The harness additions.** The matched IID order; a larger probe set stratified by time of day, so the canary reads day
/ dusk / night separately (the channel a forgetting read needs); drift anchored to the frozen well; grad norm in the
corpus; full-method checkpoints at every leg boundary; and a well/drive split with a familiarity knob that leaves the
drive bit-identical at every level. Walk-vs-IID gaps are tested with an exact seed-permutation test over all checkpoints
at once. An independent code review verified the mechanics and corrected the statistics before analysis.

**What the shallow-well null shows.** The healthy null itself moves substantially. On the joint-embedding backbone, the
walk pushes the calibrated projector collapse readers to the magnitude of Phase 0's firing bar — strongest on the night
legs — at every familiarity level, while the canary stays flat. Whether that is collapse the canary cannot see or benign
compression is the first question for P1.1.1. On MAE the internal geometry moves but the canary does not, and the
forgetting signature (daytime accuracy falling during night legs) is absent: MAE resists again. Loss and grad norm
separate walk from IID only mechanically (single-regime vs. mixed batches). Familiarity has no detectable effect, though
with one well per level and shallow wells only a large effect is ruled out. The canary turns out to be well-powered for
a paired walk-vs-IID contrast — the shared fixed probes cancel their own sampling error — so its real limit is headroom:
the wells sit only a little above chance.

**Status: 🟡 runs complete on shallow wells; the deep-well null is pending.** The loss-plateau rule stops warming in well
under one pass, leaving the canary little room to show a loss. The substudy closes on a deep-well null: apply the
review's harness fixes, add a labelled selection set to stop the well on competence rather than loss, scout the
competence ceiling across image resolutions, then re-run the primary null and a two-level familiarity check on deep
wells. The step-by-step handover is in the [detail doc](phase1/P1.1.0.md#remaining-work--handover); the shallow sweep's
artifacts are under [`phase1/artifacts/P1.1.0/`](phase1/artifacts/P1.1.0/).
